Call the registered campaign-comparison tool with a typed CampaignRequest.
It delegates to campaign_comparison.inspect_campaign with read-only SQLite.
Require exactly n accepted logical slots per treatment at six n-levels, frozen
input hashes, immutable archived values, canonical analysis manifests, current
STEP receipts when present, source maps and paired publication export hashes.
Current STEP receipt/export contracts may supersede legacy report discovery.
Original Batch execution status must remain separate from repaired scientific
completeness; never force registry state or execution_complete.

Never rename source-local PUB_index to a logical slot. Use the verified
(treatment, IBM_job_id, source PUB) join through pub_source_manifest.csv.
On BLOCKED report exact paths, expected/actual hashes and stop production work.
Do not copy/rename inputs or replace expected hashes to manufacture readiness.
Code repairs and focused offline fixture tests do not authorize production data
or report regeneration.

The canonical adapter is 03_python_automation/campaign_comparison.py; plotting
is in dependence_statistics.py. compare_105_pubs.py delegates to the same gated
CLI. Default is read-only; --authorize-output-write requires explicit operator
authorization and repeats readiness checks. New immutable flat versions use only the mitigation output roots described in
README: 01_results_and_figures/compare for PNGs and 02_run_level_data/compare
for CSV/JSON. Historical comparison_105_pubs outputs remain unchanged. Verify
600-DPI PNGs, CSVs and protected hashes; commit publication_vNNN.json last.
Reference discrepancies block affected figures and must never be labeled COMPLETE.

C/D medians and descriptive cross-n SSE/RMSE do not imply independence. No
unsupported confidence intervals or significance tests are computed. Only
verified provider usage may be included. No IBM/network calls, recovery,
collection, AUTO, campaign-state mutation or overwriting per-n exports.
